## 简体中文

3.0.2 修复 Windows 在平板姿态启动时的识别问题，并整理两平台共用图片资源与安装包路径。

- **Windows**：QV8、QV9、QV1 在没有待恢复记录且新鲜传感器几何没有冲突时，可以在启动时直接识别物理平板姿态，无需再次折叠。存在恢复记录、读取失败或几何冲突时仍保留安全校验；其他兼容机型仍需新的物理折叠事件。此修复不改变睡眠恢复规则。
- **Windows 使用说明**：补充熄屏期间展开后的键盘唤醒排查说明，并增加相应姿态交接回归测试。键盘唤醒问题的真机原因尚未确认，本版不宣称修复该问题。
- **Windows 与 Linux**：统一共用品牌图片、图标和姿态图片的资源定位与打包路径，整理 Windows 构建工具目录，并补充资源、路径和安装负载检查。姿态模式和操作方式保持不变。

支持范围保持不变：Windows 10/11（64 位），以及 Linux x86_64 GNOME Wayland。松下 QV8、QV9、QV1 提供已验证机型配置，其他 360° 翻转本仍需通过硬件兼容性检测。KDE Plasma 6 Wayland 仍为实验性支持，尚未实机验证。本次自动化检查不代替真机验收。

**升级**：Windows 用户运行 3.0.2 简体中文或英文安装程序，并按提示重启；Linux 用户升级相应发行版的软件包后注销并重新登录。无需重新校准或重设偏好。

## English

Version 3.0.2 fixes Windows posture detection when starting in tablet posture and organizes shared artwork and package paths on both platforms.

- **Windows**: On the QV8, QV9 and QV1, startup can recognize physical tablet posture directly when no recovery record is pending and fresh sensor geometry does not contradict it, without another fold. Recovery records, read failures and geometry conflicts still require safety checks; other compatible models still require a new physical fold event. This fix does not change sleep recovery rules.
- **Windows user guidance**: Adds keyboard wake troubleshooting for unfolding while the screen is off, with posture handoff regression coverage. The hardware cause of the keyboard wake issue remains unconfirmed; this version does not claim to fix it.
- **Windows and Linux**: Unifies resource lookup and package paths for shared branding, icons and posture images, organizes Windows build tools, and adds resource, path and installer payload checks. Posture modes and everyday controls are unchanged.

Platform support is unchanged: 64-bit Windows 10/11 and Linux x86_64 with GNOME Wayland. Verified machine profiles are provided for the Panasonic QV8, QV9 and QV1; other 360-degree convertibles must still pass hardware compatibility detection. KDE Plasma 6 Wayland support remains experimental and has not been verified on hardware. Automated checks for this release do not replace hardware acceptance testing.

**Upgrading**: On Windows, run the Simplified Chinese or English 3.0.2 installer and restart if prompted. On Linux, upgrade the package for your distribution, then sign out and back in. You do not need to recalibrate or reset your preferences.
