## 简体中文

3.1.0：改善 Windows 姿态识别、唤醒恢复与通知显示。

- **Windows**：QV8、QV9、QV1 使用持续读取的物理姿态识别，改善以折叠状态启动或唤醒时的识别。
- **Windows**：缩短传感器启动和唤醒后的恢复等待。
- **Windows**：恢复托盘及通知的圆角图标，并修正通知标题区图标。

**升级**：按常规方式升级，安装后按提示重启。安装方法与支持范围见[使用说明](../../README.md)。

## English

3.1.0: Improves Windows posture detection, wake recovery, and notification appearance.

- **Windows**: QV8, QV9, and QV1 continuously read physical posture, improving detection when starting or waking while folded.
- **Windows**: Reduces sensor startup and wake recovery delays.
- **Windows**: Restores rounded tray and notification icons and corrects the notification header icon.

**Upgrading**: Upgrade as usual and restart if prompted after installation. See the [user guide](../../README.en.md) for installation and supported systems.
