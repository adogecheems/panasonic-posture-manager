## 简体中文

3.0.1 修复 Linux 启动兼容性，并改善 Windows 安装程序的等待提示。

- **Linux**：修复 Ubuntu 24.04 等环境中，后台服务和桌面会话因信号处理接口不兼容而无法启动的问题；桌面会话退出时会清理已注册的信号处理资源。
- **Windows**：交互安装程序在检测旧版本和计算安装空间期间保持准备页面可见，减少初始化较慢时看不到安装窗口的困惑。此改动不缩短系统准备时间，静默安装仍不显示界面。
- **说明与检查**：新增英文使用说明，补充帐篷、支架和触摸输入的用途说明；日常检查现在覆盖完整 Linux 测试，发布前也必须通过同一源码提交的检查。

支持范围保持不变：Windows 10/11（64 位），以及 Linux x86_64 GNOME Wayland。松下 QV8、QV9、QV1 提供已验证机型配置，其他 360° 翻转本仍需通过硬件兼容性检测。KDE Plasma 6 Wayland 仍为实验性支持，尚未实机验证。本次自动化检查不代替真机验收。

**升级**：Windows 用户运行 3.0.1 简体中文或英文安装程序，并按提示重启；Linux 用户升级相应发行版的软件包后注销并重新登录。无需重新校准或重设偏好。

## English

Version 3.0.1 fixes Linux startup compatibility and improves the Windows installer's waiting feedback.

- **Linux**: Fixes background service and desktop session startup failures caused by an incompatible signal handling interface on Ubuntu 24.04 and similar environments. The desktop session also releases its registered signal resources when it exits.
- **Windows**: The interactive installer keeps its preparation page visible while detecting older versions and calculating disk space, making slower initialization easier to follow. This does not shorten system preparation time. Silent installation remains silent.
- **Documentation and checks**: Adds an English user guide and clarifies tent, stand and touch input use cases. Daily checks now include the full Linux test suite, and publishing requires checks against the same source commit.

Platform support is unchanged: 64-bit Windows 10/11 and Linux x86_64 with GNOME Wayland. Verified machine profiles are provided for the Panasonic QV8, QV9 and QV1; other 360-degree convertibles must still pass hardware compatibility detection. KDE Plasma 6 Wayland support remains experimental and has not been verified on hardware. Automated checks for this release do not replace hardware acceptance testing.

**Upgrading**: On Windows, run the Simplified Chinese or English 3.0.1 installer and restart if prompted. On Linux, upgrade the package for your distribution, then sign out and back in. You do not need to recalibrate or reset your preferences.
