## 简体中文

3.1.1：改善 Windows 物理姿态检测的兼容性与可靠性。

- **Windows**：QV8、QV9、QV1 的姿态识别不再受旧版本残留记录或无关事件来源故障影响。
- **Windows**：其他兼容翻转本也可利用设备提供的物理姿态读数，改善启动和唤醒后的识别；可用功能仍取决于实际硬件能力。
- **Windows**：物理姿态暂时不可读取时保持安全等待，并在读数恢复后重新识别，避免过早切换检测方式。

**升级**：按常规方式升级，安装后按提示重启。安装方法与支持范围见[使用说明](../../README.md)。

## English

3.1.1: Improves compatibility and reliability of physical posture detection on Windows.

- **Windows**: Posture detection on QV8, QV9, and QV1 is no longer affected by records left by older versions or failures in an unrelated event source.
- **Windows**: Other compatible convertibles can also use physical posture readings provided by their hardware, improving detection at startup and after wake; available features still depend on actual hardware capabilities.
- **Windows**: Safely waits when physical posture readings are temporarily unavailable and resumes detection when they recover, avoiding premature changes to the detection method.

**Upgrading**: Upgrade as usual and restart if prompted after installation. See the [user guide](../../README.en.md) for installation and supported systems.
